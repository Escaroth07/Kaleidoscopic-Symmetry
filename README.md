## Controls

| Key            | Action                           |
|----------------|----------------------------------|
| `ESC`          | Exit the application             |
| Up Arrow       | Increase reflections             |
| Down Arrow     | Decrease reflections             |
| Left Arrow     | Slow down                        |
| Right Arrow    | Speed up                         |
| `+`            | Increase radius                  |
| `-`            | Decrease radius                  |
